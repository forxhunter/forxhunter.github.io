# Templates and Examples

This folder contains template files and examples that are not actively used on the website but kept for reference.

## Project Examples (`project_examples/`)

Contains sample project templates from the original al-folio theme:

- `3_project.md` - Example project with redirect to external website
- `4_project.md` - Example project without image

These can be used as templates when creating new projects. Simply copy them back to the `_projects/` directory and customize as needed.

## Usage

To use a template:

1. Copy the desired template from this folder to `_projects/`
2. Rename it following the pattern `N_project.md` where N is the next number
3. Update the front matter (title, description, category, etc.)
4. Replace the content with your project details

## Note

Files in this folder are excluded from the Jekyll build process and won't appear on your website.
